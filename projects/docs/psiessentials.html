Essential PowerShell Cmdlets: A Practical Guide for Windows Administration and Security

PowerShell is one of the most powerful tools available for managing and automating Windows systems. Unlike the traditional Command Prompt, PowerShell works primarily with objects, making it especially useful for system administration, automation, troubleshooting, and cybersecurity.

In this guide, we'll cover the most important PowerShell cmdlets and concepts you should know when starting to work with PowerShell, particularly from a Windows administration and security perspective.

What is a PowerShell Cmdlet?

A cmdlet (pronounced "command-let") is a lightweight command built into PowerShell. Most cmdlets follow a simple naming convention: 

Verb-Noun

For example:

Get-Process
Get-Service
Start-Process
Stop-Process

The verb describes the action, while the noun describes the object being manipulated.

  • Get — retrieve information
  • Set — modify a configuration
  • New — create something
  • Remove — delete something
  • Start — start something
  • Stop — stop something
  • Restart — restart something

Getting Help and Discovering Commands

Before memorizing hundreds of commands, you should learn how to discover commands yourself.

Get-Command

Lists available commands or searches for commands matching a pattern. 

Get-Command

For example:

Get-Command *process*

This searches for commands related to processes.

Get-Help

Provides documentation and usage information for a cmdlet. 

Get-Help Get-Process

For more detailed information:

Get-Help Get-Process -Full

Get-Member

One of the most useful commands for understanding how PowerShell works with objects. 

Get-Process | Get-Member

It displays the properties and methods available for the objects returned by Get-Process.

Managing Processes

Processes are a fundamental part of Windows administration and security monitoring.

Get-Process

Lists currently running processes:

Get-Process

You can search for a specific process:

Get-Process -Name powershell

You can also filter processes:

Get-Process | Where-Object {$_.CPU -gt 100}

Stop-Process

Terminates a process:

Stop-Process -Name notepad

Start-Process

Starts an application or executable:

Start-Process notepad

These commands can be particularly useful when investigating suspicious processes or automating administrative tasks.

Managing Windows Services

Windows services are another important area for both system administration and security.

Get-Service

Lists installed services:

Get-Service

You can filter services by status:

Get-Service | Where-Object {$_.Status -eq "Stopped"}

Starting, stopping and restarting services

Start-Service wuauserv
Stop-Service wuauserv
Restart-Service wuauserv

Depending on the PowerShell version and object properties available, you can also inspect services based on their startup configuration.

Gathering System Information

Get-ComputerInfo

Provides detailed information about the computer: 

Get-ComputerInfo

For more specific system information, Get-CimInstance is also extremely useful. 

Get-CimInstance Win32_OperatingSystem

This can be useful when building scripts that need to identify the operating system, version, configuration, or other system properties.

Working with Files and Directories

Get-ChildItem

Lists files and directories:

Get-ChildItem C:\

Set-Location

Changes the current directory:

Set-Location C:\Windows

Copy-Item

Copies files or directories:

Copy-Item file.txt C:\Temp

Move-Item

Moves files:

Move-Item file.txt C:\Temp

Remove-Item

Removes files or directories:

Remove-Item file.txt

Get-Content

Reads the contents of a file:

Get-Content log.txt

These commands are particularly useful when analyzing logs or automating system maintenance.

User and Group Management

When performing security audits, checking local accounts and privileged groups is essential.

Get-LocalUser

Lists local user accounts:

Get-LocalUser

Get-LocalGroup

Lists local groups:

Get-LocalGroup

Get-LocalGroupMember

To check members of the local Administrators group: 

Get-LocalGroupMember Administrators

This is particularly useful during security assessments because excessive membership in privileged groups can increase the attack surface of a system.

Network Information

Get-NetIPAddress

Displays IP addresses configured on the system: 

Get-NetIPAddress

Get-NetIPConfiguration

Displays network configuration: 

Get-NetIPConfiguration

Get-NetTCPConnection

Displays TCP connections: 

Get-NetTCPConnection

You can filter for established connections:

Get-NetTCPConnection |
    Where-Object {$_.State -eq "Established"}

This can be useful during incident response or when investigating unexpected network activity.

Windows Firewall

PowerShell is also extremely useful for inspecting Windows Firewall configuration.

Get-NetFirewallProfile

Displays the status of the Windows Firewall profiles: 

Get-NetFirewallProfile

Get-NetFirewallRule

Lists configured firewall rules: 

Get-NetFirewallRule

You can filter for enabled rules:

Get-NetFirewallRule |
    Where-Object {$_.Enabled -eq "True"}

These commands are useful when auditing whether firewall protections are enabled and how traffic is being controlled.

Windows Event Logs

For cybersecurity professionals, one of the most important PowerShell cmdlets is: 

Get-WinEvent

It allows you to query Windows Event Logs directly from PowerShell.

For example, you can retrieve recent events from the Security log: 

Get-WinEvent -LogName Security -MaxEvents 20

You can also filter events by Event ID: 

Get-WinEvent -FilterHashtable @{
    LogName = "Security"
    Id = 4624
}

Event ID 4624, for example, is associated with a successful logon.

Other security-relevant events can be investigated in the same way, making Get-WinEvent extremely valuable for SOC analysts, incident response, and security auditing.

The PowerShell Pipeline

One of the most important concepts to understand in PowerShell is the pipeline: 

|

The pipeline allows the output of one command to be passed directly to another command. 

Get-Process |
    Where-Object {$_.CPU -gt 50} |
    Select-Object Name, CPU
Get data → Filter data → Select information

This approach makes PowerShell commands highly flexible.

Filtering with Where-Object

Where-Object allows you to filter objects based on a condition. 

Get-Process |
    Where-Object {$_.Name -eq "chrome"}

Another example:

Get-Service |
    Where-Object {$_.Status -eq "Stopped"}

The $_ variable represents the current object being processed by the pipeline.

Selecting Properties with Select-Object

Sometimes you don't need every property returned by a command. You can select only the information you need: 

Get-Process |
    Select-Object Name, Id, CPU

This is particularly useful when creating reports or preparing data for further analysis.

Sorting Data with Sort-Object

You can sort objects based on one of their properties. 

Get-Process |
    Sort-Object CPU -Descending

This can help identify processes consuming the most CPU resources.

Exporting Information

PowerShell becomes even more useful when the collected information needs to be saved for later analysis.

Exporting to CSV

Get-Process |
    Export-Csv processes.csv -NoTypeInformation

Exporting to a text file

Get-Process |
    Out-File processes.txt

Converting to JSON

Get-Process |
    ConvertTo-Json

These capabilities are especially useful when developing security auditing scripts, since the collected data can be transformed into structured reports.

Essential Cmdlets to Learn First

If you're learning PowerShell for Windows administration, cybersecurity, SOC operations, or security auditing, these are some of the commands worth prioritizing:

Get-Command Discover commands
Get-Help Get command documentation
Get-Member Inspect object properties and methods
Get-Process Inspect running processes
Get-Service Inspect Windows services
Get-WinEvent Analyze Windows Event Logs
Get-LocalUser List local users
Get-LocalGroupMember Inspect group membership
Get-NetIPAddress Inspect IP addresses
Get-NetTCPConnection Inspect network connections
Get-NetFirewallProfile Inspect firewall profiles
Get-NetFirewallRule Inspect firewall rules
Get-CimInstance Query system information
Where-Object Filter objects
Select-Object Select properties
Sort-Object Sort objects
Export-Csv Export data to CSV

Final Thoughts

You don't need to memorize every PowerShell cmdlet to become productive with PowerShell. In fact, learning how to discover commands, inspect objects, use the pipeline, filter data, and export results is much more valuable.

A good starting workflow is:

Get-Command
     ↓
Get-Help
     ↓
Get-Member
     ↓
Get-* command
     ↓
Where-Object
     ↓
Select-Object
     ↓
Export-Csv

Once these concepts become familiar, you can start building more advanced scripts for Windows security auditing, incident response, system hardening, and SOC automation.
