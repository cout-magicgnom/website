.PS1 DDOS DEFENDER

10/2025 - This PowerShell script is a simple automated DDoS defender that monitors TCP, ICMP (ping) and UDP endpoint connections in an infinite loop, logs events to a log file ($logPath, default: Desktop\log_ddos.txt), and blocks suspicious IPs by creating firewall rules via New-NetFirewallRule (storing blocked IPs in $ipsBloqueados), in addition to beeping and displaying an alert box when blocking; to use it, save the contents as ddos_defense.ps1 and run it in a PowerShell run as Administrator (for example: powershell -ExecutionPolicy Bypass -File .\ddos_defense.ps1), as it creates firewall rules and queries system resources; to configure, edit the $logPath, $limiteConexoesTCP, $limitePingICMP and $limiteUDP variables at the top of the file according to your tolerance needs before running (or redirect the log), and stop the script with Ctrl+C when you want to stop. PYTHON BACKUP SCRIPT

4/2026 - This script is an interactive command-line tool developed in Python for batch copying files from one directory to another. Its operation occurs through a guided walkthrough where the system asks the user for the path to the source folder, lists the content found and requires a security confirmation before proceeding. MALWARE KNOWLEDGE

03/2026 - This script is a malicious program (malware) known as Reverse Shell, designed to provide an attacker with remote control over the victim's computer. The tool initially works by moving your own file to a temporary system folder (as a form of hiding) and opens a PDF file in the browser to trick the user, creating a distraction while running in the background. The code then establishes a direct network connection to the attacker's IP address and port and enters a continuous cycle: it waits to receive remote commands, executes them silently in the victim's operating system terminal, and finally sends the results or possible error messages back to the server of whoever is controlling it. ALGORITHM ANALYSIS

05/2026 - This C script is an automatic language detector based on statistical analysis, designed to identify whether a text is written in Portuguese, English or Esperanto. The tool works by counting the number of each letter present in the sentence typed by the user and transforming this numerical data into percentage frequencies. She then compares this distribution with an internal table that contains the expected pattern of letter usage for each of the three languages, calculating the difference (or "margin of error") between them. The language that presents the smallest statistical variation in relation to the text entered is declared the winner, using the frequency of the letters as a kind of "fingerprint" to guess the correct language.
